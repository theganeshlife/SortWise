Is your Desktop buried in screenshots and your Downloads folder a pile of Document3.docx and Book1.xlsx? SortWise reads what each file is about and puts it where it belongs, then keeps it that way.

**Windows**
- `SortWiseSetup-1.0.0.exe`: installer. No admin rights needed.
- `SortWise-1.0.0-portable.exe`: runs without installing.

If Windows says "Windows protected your PC", choose **More info › Run anyway**.

**Mac**
- `SortWise-1.0.0-mac-apple-silicon.dmg`: Macs with Apple silicon (M1 and later).
- `SortWise-1.0.0-mac-intel.dmg`: Macs with Intel processors.

Drag SortWise into Applications. The first time you open it, go to **System Settings › Privacy & Security** and choose **Open Anyway**.

**Highlights**
- Sort this folder: every loose file goes into the folder whose contents match, or into a new topic folder, with folders inside folders for big subjects.
- New files are sorted automatically as they arrive, including downloads once they finish.
- Duplicate photos, videos, documents and folders shown side by side.
- Search across file names, folders, the text inside documents, and your tags and notes.
- One-click updates from the About page.
